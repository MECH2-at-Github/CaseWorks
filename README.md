Welcome to the repository for CaseWonks, a user script designed for CaseWorks. If you find a bug with the script, either email me or submit it as an issue.

# FAQs
Q:&ensp;What does it do?  
A:&ensp;Mostly changes text in tables (doc types, short notes, links, dates/times, etc.). Some links are changed to open in new tabs.  
&emsp;[Plus some other things](https://github.com/MECH2-at-Github/CaseWorks/wiki)

Q:&ensp;Is it stable?  
A:&ensp;As stable as anyone working in CaseWorks.

Q:&ensp;Is it safe to use?  
A:&ensp;All changes are client side (your browser); there's no data sent by the script anywhere.  
&emsp;CaseWonks does not directly submit any forms; the user is still required to click buttons to save changes.
  
Q:&ensp;Is this sanctioned by NCT?  
A:&ensp;It's neither sanctioned nor acknowledged by them. NCT is welcome to implement any enhancements added to this script, but due to limited resources this is unlikely.  
  
Q:&ensp;Is this sanctioned by SLC?  
A:&ensp;It's not sanctioned by SLC IT, but it is acknowledged by my supervisor. Everyone is welcome to use the script with this understanding.  
  
Q:&ensp;Why did you make this?  
A:&ensp;I don't like to be miserable while I work.
  
Q:&ensp;I work in the ___ Edition, will it work for me?  
A:&ensp;If it doesn't, I'll do my best to make it work.  
&emsp;If a table's text isn't shortened, the most likely point of failure is a mismatch of table columns.

# Installation

Tip: Right click links and then click "Open link in new tab". Tabs can be closed after doing the install.

1. Install a UserScript extension, such as [TamperMonkey (Edge)](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd).  (Right click, open link in new tab)
   Alternative (untested) extensions are ViolentMonkey and GreaseMonkey.  
1a. Due to Edge browser changes, you must enable "Developer Mode" and "Allow User Scripts" on Edge's Extension page.
   * On [Extensions](edge://extensions/), the Developer Mode slider is located on the left bar.
   * On the Extensions page, click the "Details" button under Tampermonkey, and then click the checkbox or slider for "Allow User Scripts".  
    (Edge visual instructions)
     <img width="900" alt="Edge Install Visual" src="https://github.com/user-attachments/assets/e812fc52-67d4-4ed9-a935-b23d841bf491" />


3. Open [CaseWonks install](https://github.com/MECH2-at-Github/CaseWorks/raw/refs/heads/main/CaseWonks.user.js) and click the [ Install ] button. (Right click, open link in new tab)  
4. Install [Stylus](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne). (Right click, open link in new tab) (Ignore the fact that this is the Chrome store. Edge is a Chromium browser, so it will install and work. Do NOT install Stylus from the Edge store. It is not the same extension and will not work.)
5. Open the [style install page](https://userstyles.world/style/27371/default-slug) and click the [ Install ] button to the bottom right of the image. (Right click, open link in new tab)  
On the next page, click the [ Install Style ] button in the upper left. <img width="600" alt="style sheet install" src="https://github.com/user-attachments/assets/ed4dd0cb-e03d-4315-8b43-5b5fc81ef9fc" />

Done! Close any tabs that were opened as part of the installation process. And don't forget to check out the [wiki page](https://github.com/MECH2-at-Github/CaseWorks/wiki) to learn about CaseWonks' features.
